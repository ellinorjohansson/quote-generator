# Quote Generator

Quote Generator is a simple and clean app built with HTML, Sass, and TypeScript. The app displays inspiring, funny, or thoughtful quotes one at a time. 

## Table of Contents

- [Tech Stack](#tech-stack)
- [Features](#features)
- [Installation](#installation)
- [Authors](#authors)

## Features
* Click Generate Quotes to begin generating quotes.
* Display one quote at a time.
* Navigate through quotes using the Generate Quote button.
* Add quotes to a Favorites list.

## Installation

Install quote-generator locally with npm

```bash
# Clone this repository
$ git clone https://github.com/ellinorjohansson/quote-generator

# Go into the repository
$ cd quote-generator

# Install dependencies
$ npm install

# Run app
$ npm run dev
```
